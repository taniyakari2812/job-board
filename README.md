# Job Board

A job listing web app built with React, TypeScript, and Vite. Fetches live remote job postings from a public API and lets users search and view job details.

## Features
- Fetches real-time job listings from the Remotive public API
- Search/filter jobs by title or company
- Click a job to view full details and apply link
- Built with functional components and React hooks (useState, useEffect)
- Fully typed with TypeScript

## Tech Stack
- React
- TypeScript
- Vite
- Remotive API (https://remotive.com/api/remote-jobs)

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/taniyakari2812/job-board.git
cd job-board
npm install
npm run dev
```

Open the local URL shown in the terminal (usually http://localhost:5173).
